# ORTO OrcaSlicer

**ORTO OrcaSlicer** — специализированный форк [OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer), развиваемый для интеграции с производственной экосистемой **ORTO** и подготовки 3D-моделей косметических оболочек протезов.

Это не отдельная замена обычному OrcaSlicer для повседневной ручной нарезки. ORTO Edition предназначена прежде всего для автоматизированного производственного сценария, в котором управляющее приложение ORTO передаёт модели слайсеру и использует его возможности подготовки и последующей обработки.

> Исходный проект OrcaSlicer и его документация: [orcaslicer_readme.md](./orcaslicer_readme.md).

## Назначение форка

Основная задача ORTO OrcaSlicer — встроить специализированную подготовку косметических оболочек непосредственно в рабочий процесс ORTO, сохранив возможности и интерфейсную основу OrcaSlicer.

Разработка ведётся в отдельной ветке `orto-dev`. Изменения форка не предназначены для внесения в upstream OrcaSlicer.

## Специализированная подготовка оболочки

В форк добавлена команда контекстного меню:

**ORTO: Prepare cosmetic shell**

Она выполняет подготовку выбранной модели:

1. Поворачивает оболочку на **+90° вокруг оси X**.
2. Размещает модель так, чтобы нижняя точка оболочки находилась на высоте **3 мм над плоскостью стола**.
3. Создаёт нативный модификатор типа **Support Blocker** — это именно штатный тип объёма OrcaSlicer, а не обычная деталь модели.
4. Размещает блокиратор с учётом габаритов оболочки и рабочей области стола, с запасом **10 мм** по XY. Нижняя граница блокиратора — **Z = 20 мм**, высота — **700 мм**.
5. Обновляет сцену, чтобы результат подготовки сразу отображался в интерфейсе.

Команда размещена в верхней части контекстного меню и отделена от стандартных команд OrcaSlicer.

Повторное применение к уже подготовленной модели защищено от создания второго ORTO-блокиратора. Для возврата к исходному состоянию можно использовать Undo.

## Интеграция с ORTO

Целевой сценарий работы:

1. Управляющая система ORTO запускает ORTO OrcaSlicer и передаёт ему модель через командную строку.
2. ORTO OrcaSlicer автоматически выполняет подготовку оболочки и создаёт Support Blocker.
3. После успешной подготовки оператор получает информационное окно с напоминанием проверить расположение шва модели.
4. Оператор проверяет шов и самостоятельно запускает экспорт G-code.

Текст уведомления оператору:

> Убедитесь в расположении шва модели и можете экспортировать файл Gcode

**Статус интеграционного сценария:** автоматический запуск подготовки через CLI и уведомление оператора запланированы к реализации. На текущем этапе подготовка доступна через команду контекстного меню; не следует считать автоматический CLI-сценарий уже реализованным.

## Сборка и разработка

- Основная рабочая ветка форка: `orto-dev`.
- Репозиторий: [midnight1979/ORTO-OrcaSlicer](https://github.com/midnight1979/ORTO-OrcaSlicer).
- [История изменений ветки orto-dev](https://github.com/midnight1979/ORTO-OrcaSlicer/commits/orto-dev).
- [GitHub Actions](https://github.com/midnight1979/ORTO-OrcaSlicer/actions) — автоматические проверки и сборки.
- [ORTO Quick Build](https://github.com/midnight1979/ORTO-OrcaSlicer/actions/workflows/orto-quick-build.yml) — ускоренная Windows-сборка для проверки изменений и получения тестового portable-артефакта.
- Полная сборка OrcaSlicer использует upstream-инструкции: [How to build OrcaSlicer](https://www.orcaslicer.com/wiki/how_to_build).

Для разработки изменений ORTO используйте ветку `orto-dev`. Не отправляйте коммиты форка непосредственно в `main`.
